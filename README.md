### 📌 What I've built

**🏭 DXSCADA – Machine Monitoring System**
A system that tracks 48 crimping machines in a wire-harness factory. I wrote the ESP32 and Arduino firmware that reads RFID tags and counts applicator shots, the C# services that make reports and backups, and the web dashboard supervisors use to see which machines are down.
`PHP` `CodeIgniter` `MySQL` `C#` `ESP32` `Arduino` `RFID`

**👥 HRMS – HR and Payroll System**
An HR and payroll system with 62 modules. It computes SSS, PhilHealth, Pag-IBIG and BIR tax every cutoff, takes attendance from ZKTeco biometric devices, and routes leave and overtime requests to the right approvers.
`PHP` `CodeIgniter` `MySQL` `JavaScript` `GitHub Actions`

**🍽️ Canteen Meal Stub System**
A barcode meal-stub system for two plant canteens. The kiosks keep working when the internet is down and sync the scans later, so no meal records are lost.
`PHP` `CodeIgniter` `MySQL` `REST API` `Barcode`
